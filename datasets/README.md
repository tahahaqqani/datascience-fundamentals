# Datasets

All paths in notebooks use `../../datasets/<filename>` from topic folders under `notebooks/`.

| File | Used in | Description |
|------|---------|-------------|
| `data.csv` | Data preprocessing | Mixed numeric/categorical data with missing values |
| `admittance.csv` | Logistic regression | University admission (GRE, GPA, admit) |
| `social-network-ads.csv` | Classification notebooks | Age, salary, purchased (binary) |
| `position-salaries.csv` | Regression, decision trees, SVR | Job level vs salary |
| `sat-gpa.csv` | Linear regression | SAT scores vs GPA |
| `salary-data.csv` | Linear regression | Years of experience vs salary |
| `used-cars.csv` | Linear regression | Car features vs price |
| `startups-data.csv` | Linear regression | Startup spend vs profit (multiple R&D regions) |
| `country-clusters.csv` | K-means | Country development indicators |
| `customer-segmentation.csv` | K-means | Customer annual income & spending score |
| `mall-customers.csv` | K-means | Mall customer demographics & spending |
| `audiobooks-data.csv` | Neural nets | Audiobook conversion features |
| `churn-modeling.csv` | Neural nets | Bank customer churn |
| `restaurant-reviews.tsv` | NLP sentiment, LDA | Review text + liked (0/1) |
| `tripadvisor_hotel_reviews.csv` | NLP preprocessing | Hotel review text |
| `bbc_news.csv` | NLP spaCy | BBC news headlines (category labels) |
